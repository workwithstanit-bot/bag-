# MudVault

Website for MudVault, a cleat bag with a built-in stud scraper, a pull-out mud tray and charcoal odor pods. Made for a class Shark Tank project.

- `index.html` is the product page (film, how it works, details, clubs, specs).
- `store.html` is the demo store with a bag and a demo checkout. It never asks for payment details.
- Photos were made with AI in Canva. The hero film was cut from those AI photos.
- The clubs and partners shown on the site are fictional.

It's a static site with no build step. Vercel serves it as is.
